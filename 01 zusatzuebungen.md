# Zusatzübungen 01 – Was ist KI?

Passt zu Cheatsheet `01_was_ist_ki.md`. Alle Aufgaben funktionieren mit jedem KI-Dienst, auch mit einem kostenlosen Plan.

**Sicherheitsregel:** Nutze nur erfundene oder anonymisierte Daten. Lösungsansätze stehen am Ende. Schau erst nach, wenn du fertig bist.

---

## Aufgabe 1 ★ Einstieg: Begriffe zuordnen

**Ausgangslage:** Ein Kollege sagt: „Das ist doch alles dasselbe: KI, maschinelles Lernen, LLM.“

**Aufgabe:** Ordne jedem Begriff die passende Beschreibung zu.

| Begriff | Beschreibung |
|---|---|
| 1. KI | A. Das Programm lernt aus vielen Beispielen, statt feste Regeln zu bekommen. |
| 2. Maschinelles Lernen | B. Ein Sprachmodell, das Text erzeugt, indem es das wahrscheinlich nächste Wort vorhersagt. |
| 3. LLM | C. Oberbegriff für Programme, die Aufgaben lösen, für die man sonst menschliches Denken braucht. |

**Hinweis:** Gehe vom Allgemeinen zum Speziellen. Ein LLM ist ein Sonderfall.

---

## Aufgabe 2 ★★ Alltag: Wofür taugt die KI?

**Ausgangslage:** Du hast sechs Aufgaben auf deiner Liste.

**Aufgabe:** Sortiere jede Aufgabe in eine Gruppe:
- **Gut geeignet:** KI kann den Großteil übernehmen
- **Nur mit Prüfung:** KI hilft, aber du kontrollierst das Ergebnis
- **Besser anders lösen:** Nimm ein anderes Werkzeug oder eine andere Quelle

Aufgaben:
1. Einen Geburtstagsgruß für Person A formulieren
2. Einen langen Newsletter in fünf Sätzen zusammenfassen
3. Wissen, ob die Bäckerei um die Ecke heute offen hat
4. Eine Rechnung mit mehreren Posten exakt ausrechnen
5. Drei Ideen für ein Wochenende mit Freunden sammeln
6. Die Quelle für eine Statistik in einer Präsentation nennen

**Hinweis:** Denke an die Stärken und Schwächen aus dem Cheatsheet. Frage dich: Was passiert, wenn die Antwort falsch ist?

---

## Aufgabe 3 ★★ Alltag: Selbstbewusst, aber falsch?

**Ausgangslage:** Du willst herausfinden, wie die KI mit etwas umgeht, das es nicht gibt.

**Aufgabe:** Stelle deiner KI diese Frage. Das Buch ist frei erfunden.

```
Fasse mir den Roman „Der Mondgarten von Person A“ in drei Sätzen zusammen.
```

Beurteile die Antwort:
- Gibt die KI zu, dass sie das Buch nicht kennt?
- Oder erfindet sie eine Handlung?

Stelle danach eine Folgefrage:

```
Woher weißt du das? Wie sicher bist du dir?
```

**Hinweis:** Beide Ergebnisse sind lehrreich. Wenn die KI erfindet, siehst du, wie überzeugend Unsinn klingen kann. Wenn sie ehrlich antwortet, siehst du, wie ein gutes Ergebnis aussieht.

## Aufgabe 4 ★★★ Herausforderung: Chatbot, Suchmaschine, Mensch

**Ausgangslage:** Du planst einen Ausflug mit deiner Familie am Wochenende.

**Aufgabe:** Stelle dieselbe Frage an drei Stellen:
1. an eine Suchmaschine
2. an einen KI-Chatbot
3. an einen Menschen (Freundin, Kollege, Nachbar)

```
Welche drei Ausflugsziele eignen sich für ein Wochenende mit Kindern in [deiner Region]?
```

Fülle die Tabelle mit eigenen Worten aus:

| Kriterium | Suchmaschine | Chatbot | Mensch |
|---|---|---|---|
| Wie aktuell ist die Antwort? | | | |
| Kann ich die Quelle prüfen? | | | |
| Wie gut passt sie zu mir? | | | |
| Wer trägt Verantwortung? | | | |

Schreibe zum Schluss einen Satz: Für welche Frage nimmst du künftig welches Werkzeug?

**Hinweis:** Es gibt keine einzige „beste“ Quelle. Manche Chatbots nutzen auch eine Websuche. Notiere, ob deiner das tut.

## Lösungsansätze

**Aufgabe 1:** 1 → C, 2 → A, 3 → B. KI ist der Oberbegriff, maschinelles Lernen ein Weg dorthin, ein LLM eine Form davon für Sprache.

**Aufgabe 2:** Mögliche Einordnung:
- *Gut geeignet:* 1 (Geburtstagsgruß), 2 (Zusammenfassung, bei kurzem Text lässt sich das leicht gegenlesen), 5 (Ideen sammeln)
- *Nur mit Prüfung:* 2 bei wichtigen Inhalten, denn Details können fehlen oder falsch sein
- *Besser anders lösen:* 3 (aktuelle Öffnungszeiten: Webseite oder Anruf), 4 (exakte Rechnung: Taschenrechner oder Tabelle), 6 (Quelle: Originalquelle suchen, die KI kann Quellen erfinden)

Wichtig ist deine Begründung: Je folgenreicher ein Fehler, desto mehr prüfst du.

**Aufgabe 3:** Zwei Ergebnisse sind möglich.
- *Die KI räumt ein, das Buch nicht zu kennen:* Das ist das gewünschte Verhalten. Du kannst solche Antworten gezielt fördern, z. B. mit „Sag ‚weiß ich nicht‘, wenn du unsicher bist.“
- *Die KI erfindet eine Handlung:* Das ist eine Halluzination, eine erfundene, aber überzeugend klingende Antwort. Merke dir: Der sichere Ton sagt nichts über die Richtigkeit aus. Mehr dazu in Cheatsheet 08.

Auch eine Folgefrage nach der Sicherheit garantiert keine Wahrheit. Prüfe in einer unabhängigen Quelle.

**Aufgabe 4:** Typische Beobachtungen (deine können abweichen):
- *Suchmaschine:* meist aktuell, Quellen sichtbar, du musst selbst auswählen und lesen.
- *Chatbot:* schnell und gut formuliert, aber Aktualität und Quellen hängen davon ab, ob eine Websuche genutzt wird. Prüfe Angaben.
- *Mensch:* kennt dich und deine Region, aber nur mit begrenztem Überblick. Verantwortung liegt bei dir, ein Mensch kann nachfragen und Erfahrung einbringen.

Ein sinnvoller Schlusssatz könnte lauten: „Für aktuelle Fakten nutze ich die Suchmaschine, für Ideen und Formulierungen den Chatbot, für persönliche Entscheidungen frage ich zusätzlich einen Menschen.“
