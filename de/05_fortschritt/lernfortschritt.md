Hier siehst du, wo du im Training stehst. Kopiere die Datei und hake ab, indem du `☐` durch `☑` ersetzt.

**Mein Lernpfad:** ☐ Schnellstart ☐ Standard ☐ Fortgeschritten
**Startdatum:** ____________

---

## 1. So nutzt du die Checkliste

- **gelesen:** Du hast das Cheatsheet durchgearbeitet.
- **geübt:** Du hast die Übung (5 Min.) mit einem KI-Dienst gemacht.
- **Pfad:** Zeigt, ab welchem Lernpfad das Thema dazugehört.
  - **S** = Schnellstart (gilt für alle, auch für Standard und Fortgeschritten)
  - **St** = Standard (und Fortgeschritten)
  - **F** = nur Fortgeschritten
- **Zusatzübungen** sind freiwillig. Notiere sie bei „Notizen“, wenn du sie gemacht hast.

## 4. Selbsteinschätzung (Skala 1–5)

**1** = trifft gar nicht zu · **3** = teils, teils · **5** = trifft voll zu

Trage **vorher** (vor Cheatsheet 01) und **nachher** (nach dem Abschluss deines Lernpfads) eine Zahl ein. Aussagen mit **(F)** gehören zum Fortgeschrittenen-Pfad.

| Aussage | Vorher | Nachher |
|---|---|---|
| Ich kann erklären, was ein KI-Chatbot kann und was nicht. | | |
| Ich weiß, welche Daten nicht in einen Chat gehören. | | |
| Ich kann einen guten Prompt schreiben. | | |
| Ich erkenne erfundene Antworten (Halluzinationen) und prüfe sie. | | |
| Ich erkenne Prompt Injection (versteckte Anweisungen in fremden Inhalten). | | |
| Ich kann einschätzen, welches Modell und welche Einstellung zu einer Aufgabe passen. | | |
| Ich habe Kosten und Limits im Blick. (F) | | |
| Ich weiß, was Agents, APIs und MCP sind. (F) | | |
| Ich kann Agenten mit minimalen Rechten und Freigaben absichern. (F) | | |

## 5. Meine Prompt-Bibliothek

Sammle gelungene Prompts ab Tag 1 in einer eigenen Notizdatei (Vorlage in Cheatsheet 23). Hier hakst du den Stand ab:

- ☐ Notizdatei für die Prompt-Bibliothek angelegt
- ☐ Die ersten 3 Prompts gesammelt
- ☐ 10 Prompts gesammelt
- ☐ Prompts mit Titel, Zweck und Beispiel-Ergebnis versehen

Denk daran: Speichere nur **erfundene oder anonymisierte** Inhalte.
