# Capstone-Checkliste: Selbstbewertung

Bewerte dein Capstone-Projekt selbst – Kriterium für Kriterium, nicht nach Gefühl. Das Verfahren ist dasselbe wie beim Selbstbewertungsraster der Tests: prüfen, Punkte vergeben (0 / 0,5 / volle Punktzahl), am Ende zählen. **Im Zweifel die niedrigere Wertung.**

**Gesamt: 24 Punkte · Bestehensgrenze: 17 Punkte**

---

## 1. Phasen abhaken

- [ ] Abschlusstest bestanden (75 %)
- [ ] Phase 1: 3 Aufgaben identifiziert und priorisiert
- [ ] Phase 2: Prompt-Bibliothek fertig (10+ Einträge)
- [ ] Phase 3: Sicherheitskonzept + Agent-Lite-Konzept + Reflexionsnotiz

---

## 2. Lieferobjekt 1: Prompt-Bibliothek (10 Punkte)

| Nr. | Kriterium | Punkte | Meine Wertung |
|---|---|---|---|
| a | 10+ Prompts vorhanden, jeder mit Zweck und typischer Nutzungssituation | 2 | |
| b | Jeder Prompt hat Vorher/Nachher-Fassung mit benannter Technik | 3 | |
| c | Mindestens 4 verschiedene Techniken kommen vor (Rolle, Kontext, Constraints, Format, Beispiele) | 2 | |
| d | Testnotizen vorhanden – nachvollziehbar, warum „Nachher" besser ist | 1 | |
| e | Keine sensiblen oder personenbezogenen Daten (**hartes Kriterium**: erfüllt oder 0) | 2 | |

**Zwischensumme:** ____ / 10
