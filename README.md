# KI-Training für Einsteiger

Selbststudium-Training, um KI-Chatbots **sicher, sinnvoll und kostenbewusst** zu nutzen. Herstellerneutral – alles funktioniert mit jedem gängigen Dienst (z. B. ChatGPT, Claude, Gemini, Copilot). Keine Vorkenntnisse nötig.

## So startest du

1. Lies das Einführungs-Handout: [`00_einfuehrung_handout.md`](00_einfuehrung_handout.md) – ca. 15 Min., enthält die fünf Sicherheitsregeln und die Checkliste „Startklar machen“.
2. Wähle deinen Lernpfad (Schnellstart, Standard oder Fortgeschritten) – Details in der [Roadmap](KI-Training_Roadmap.md).
3. Arbeite die Themen in Nummernreihenfolge durch. Pro Thema (ca. 25–30 Min.): Cheatsheet lesen → Übung machen → ggf. Zusatzübungen → Test nach dem Block.
4. Hake deinen Fortschritt ab: [`05_fortschritt/lernfortschritt.md`](05_fortschritt/lernfortschritt.md)
