# Question template for GitHub Issues

Use this template when you get stuck on an exercise or a topic. Create a **new issue** in the GitHub repo (the "Issues" tab → "New Issue") and paste the completed template there.

**Important:** Issues are **publicly visible**. No sensitive or personal data in issues. Anonymize prompts and results ("Person A", "Company X") before pasting them (see Cheatsheet 04).

---

## Template

```
Topic / Cheatsheet no.: ____ (e.g. "06 – Prompt techniques")

1. What did you want to achieve?
   (Goal in one sentence, e.g. "I wanted the AI to create
   a table from my list of expenses.")

2. What did you try?
   (Paste your prompt and the result – anonymized!)

3. Where are you stuck?
   (What is different from what you expected? Which error message,
   which unexpected result?)

4. What have you already tried?
   (e.g. "Rephrased the prompt twice, started a new chat")

5. Urgency:
   ( ) low – no time pressure
   ( ) medium – would be good by [date/time frame]
   ( ) high – blocking my learning progress
```

---

## Notes

- **Before creating an issue:** Check the FAQ (`04_trainer/faq`) and existing issues – many questions have already been answered there. You can simply reinforce existing issues with "+1" or a comment.
- **One topic per issue:** This keeps questions easy to find and cleanly closeable.
- **The more specific, the faster the help:** A prompt people can actually see often saves two follow-up questions.
- **Learning by asking:** Your question (anonymized) can be added to the FAQ and help other participants. Solved issues are closed, but remain available as a reference.
