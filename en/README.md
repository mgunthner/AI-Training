# AI Training for Beginners

A self-study training for using AI chatbots **safely, sensibly and with cost awareness**. Vendor-neutral – everything works with any common service (e.g. ChatGPT, Claude, Gemini, Copilot). No prior knowledge needed.

## How to start

1. Read the introduction handout: `00_introduction_handout` – about 15 min., contains the five safety rules and the "Getting ready to start" checklist.
2. Choose your learning path (quick start, standard or advanced) – details in the roadmap (`AI-Training_Roadmap`).
3. Work through the topics in numerical order. Per topic (about 25–30 min.): read the cheatsheet → do the exercise → extra exercises if needed → test after the block.
4. Tick off your progress: `05_progress/learning_progress`
