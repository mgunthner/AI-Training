# AI Training for Beginners

Self-study training to use AI chatbots **safely, sensibly and cost-consciously**. Vendor-neutral, no prior knowledge required.

## Status

The English version is **in progress**. The complete original material is available in German:

- German original: `../de/` (`../de/README`)

Once translated, this folder will mirror the structure of `de/`:

| Folder / file | Content |
|---|---|
| `00_einfuehrung_handout` | Introduction handout (start here) |
| `01_cheatsheets/` | Cheatsheets, one page each |
| `02_zusatzuebungen/` | Extra exercises per topic (★ / ★★ / ★★★) |
| `03_tests/` | Entrance test and block tests with separate solutions |
| `04_trainer/` | Question template and FAQ |
| `05_fortschritt/` | Progress checklist |
| `KI-Training_Roadmap` | Learning paths and topic plan |

PDF downloads for each language are available under [`../pdf/<language-code>/`](../pdf/).
