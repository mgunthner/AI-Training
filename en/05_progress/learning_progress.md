## 1. How to use the checklist

- **read:** You have worked through the cheatsheet.
- **practiced:** You have done the exercise (5 min.) with an AI service.
- **Path:** Shows from which learning path the topic is included.
  - **S** = Quick start (applies to everyone, including Standard and Advanced)
  - **St** = Standard (and Advanced)
  - **F** = Advanced only
- **Extra exercises** are voluntary. Note them under "Notes" if you did them.
