# 23 – Everyday workflows & prompt library

**Definition:** A **workflow** is a fixed sequence of steps for a recurring task. The **prompt library** is your collection of tried-and-tested prompts for it – built once, used again and again.

> **Remember:** Getting a good result once is luck. Making it repeatable is method.

## Key points
- **Spot recurring tasks:** Anything you do more than once (summarizing emails, building study plans, evaluating spreadsheets) is worth a workflow.
- **Structure of a workflow:** Starting point → prompt (from the library) → check the quality → save/adjust.
- **Library structure per entry:** title, purpose, the finished prompt, example result (anonymized), if needed a note (which model, which setting).
- **Mini quality check before using it:** Is it correct (facts, figures)? Am I allowed to share it (data, rights, topic 22)? Is it my style (tone, length)?
- **When AI, when not:** AI for text, structure, ideas, routine. Not for tasks where reliability or the relationship matters and you can't check it (contracts, conflicts, personal messages to people close to you).
- **Maintenance:** Review your library regularly – sort out or sharpen up prompts that no longer work.

## Example
**Eight standard workflows to start with** (all with made-up data):

1. **Summarize and answer email:** Paste the email → "Summarize this and suggest three reply variants: short, friendly, formal."
2. **Summary:** Paste the text → "Summarize in five bullet points, audience: a manager with no specialist knowledge."
3. **Study plan:** State the topic and time budget → "Create a plan as a table, at most one topic per day, day 7 off."
4. **Research preparation:** "Ask the 10 questions you need answered before you research."
5. **Text revision:** Text + "Improve clarity and structure. Don't change the meaning. List your changes at the end."
6. **Spreadsheet help:** Paste the raw data → "Turn this into a table with sensible columns and point out anything notable."
7. **Decision preparation:** Describe the situation → "Create a pros and cons table with the three most important criteria on each side."
8. **Meeting preparation:** Topic list → "Create an agenda with time blocks and one objective per item."

**Library entry (template):**

| Field | Content |
|---|---|
| Title | Email triple reply |
| Purpose | Respond quickly and in a structured way to incoming emails |
| Prompt | "Summarize the following email in 2 sentences and suggest 3 reply variants: short and concise, friendly-neutral, formal. Email: [TEXT]" |
| Example result | Three variants of 3–5 sentences each, made-up customer "Person A" |
| Note | Works better without the thinking mode |

## Do / Don't
| Do | Don't |
|---|---|
| Save every successful prompt right away | Start from scratch and reword every time |
| Check results before using them | Fill library entries with real data |
| Improve prompts iteratively | Keep failed prompts without reworking them |

## Mini checklist
- [ ] I have set up a notes file as my prompt library.
- [ ] I have my first three entries with title and purpose.
- [ ] I check every result with the mini quality check.
- [ ] I rework entries that no longer deliver.

## Exercise (5 min.)
Pick one of the eight standard workflows. Test it in your chat with made-up data. If the result fits: save the prompt and the example result (anonymized) as your first library entry. If not: improve the prompt over two rounds and then save it.
